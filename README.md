# breasts.python
이 코드는 작음 마음과 큰 마음을 python으로 표현한 예술입니다. 코드를 실행하게 되면 처음에 큰 게 좋은지 작은 게 좋은 지 물어보고, 답안에 따라 답안에 걸맞는 이미지가 출력됩니다. 큰 게 좋다고 하면 폭이 넓은 이차함수 그래프가 중심이 되는 아름다운 여성의 신체모습이 출력되고, 작은 게 좋다고 하면 폭이 좁은 이차함수 그래프가 중심이 되는 아름다운 여성의 신체모습이 출력됩니다. 이 코드에 담긴 의미는 자신이 외적으로 어떻든, 당신은 당신이기에 아름답다는 의미를 담고 있습니다. 제가 지금까지 만들었던 작품들과 비교했을 때, 따뜻한 의미를 지니고 있죠. 부디 이 작품으로 인해 힘을 얻는 사람이 있었으면 좋겠습니다.
