# breasts.python
This code is a work of art expressing the concepts of a small heart and a big heart using Python. When you run the code, it first asks whether you prefer a large or small heart, and an image corresponding to your answer is displayed. If you choose to prefer a large heart, an image of a beautiful woman's body centered on a wide quadratic graph is displayed; if you choose to prefer a small heart, an image of a beautiful woman's body centered on a narrow quadratic graph is displayed. The meaning behind this code is that, regardless of your outward appearance, you are beautiful simply because you are you. Compared to the works I have created so far, this one carries a warm message. I sincerely hope that someone finds strength through this piece.
